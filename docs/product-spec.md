# AIDanceFlow 产品说明文档

## 1. 项目背景

赛题⑤要求设计一款面向 KOC 的社媒 AI Agent，通过 AI 能力提供内容方向、选题建议、发布策略、互动优化等服务，帮助普通创作者低成本、高效率实现账号成长。

AIDanceFlow 选择“热点手势舞开拍”作为切入场景。手势舞和轻舞蹈内容在视频号、抖音、小红书等平台具有传播门槛低、模仿性强、适合普通用户参与的特点，但普通 KOC 往往卡在选题、动作学习、拍摄执行和发布运营上。AIDanceFlow 将这些环节整合为一个可展示的产品闭环。

## 2. 产品定位

AIDanceFlow 是一款面向普通 KOC 的热点手势舞开拍 Agent。

一句话定位：AI 帮你判断今天拍什么、拆解怎么拍，并带你完成练习录制和发布准备。

产品不是单纯合拍工具，也不是只生成数字人视频。它的核心差异是把“热点理解”和“拍摄执行”连接起来：先分析什么内容适合拍，再生成可跟拍参考，最后进入手机化练习录制，并给出发布建议。

## 3. 用户需求分析

目标用户：

1. 视频号、抖音、小红书等平台的普通 KOC。
2. 希望追热点但缺少专业运营能力的个人创作者。
3. 有表达意愿但动作学习、拍摄执行能力较弱的新手用户。

核心痛点：

1. 内容定位模糊：不知道今天拍什么，看到热点也无法判断是否适合自己的账号。
2. 选题效率低：热点变化快，普通用户很难快速做出选择。
3. 动作学习难：热门手势舞节奏快，手部细节和卡点难以看清。
4. 拍摄不专业：不知道站位、镜头、光线、节奏和表情如何配合。
5. 发布运营弱：拍完后缺少标题、标签、发布时间和评论区互动策略。

## 4. 产品设计思路

产品将一次热点内容生产拆成四步：

1. 选题：通过今日热榜、热度增长、适合拍评分和难度，让用户快速选出可拍内容。
2. 拆解：围绕爆点、光线、镜头、动作分段、发布时间和互动建议，输出可执行方案。
3. 开拍：通过 AI 领拍参考、手机化相机、倍速练习、镜像和骨架匹配，帮助用户完成录制。
4. 发布：录制完成后回放、保存，并提供可直接使用的发布和互动建议。

设计原则：

1. 面向普通用户，不在前台暴露复杂模型、提示词或投放术语。
2. 强调“可执行”，每个建议都要能转化为拍摄动作。
3. 保证演示稳定，线上 AI 生成失败或排队时使用本地示例兜底。
4. 保持完整闭环，让评审能看到从热点到成片的端到端流程。

## 5. 功能架构

### 5.1 热点趋势首页

首页展示 3 条热点手势舞趋势，每条卡片包含：

- 作品预览视频。
- 热度增长。
- 适合拍评分。
- 难度标签。
- 内容描述和动作标签。
- 开拍入口和拆解入口。

用户可以通过卡片快速判断“今天拍哪条更合适”。

### 5.2 AI 解析与方案确认

点击开拍后，系统进入解析状态，展示：

- 同源作品解析中。
- 动作解析中。
- 去噪中。
- 清晰化中。

该状态会至少停留约 3 秒，让用户能看清 AI 处理流程。解析完成后，用户看到领拍参考和原作品对照，再确认进入拍摄。

### 5.3 趋势拆解页

趋势拆解页输出运营和拍摄建议：

- 爆点在哪里。
- 光线怎么打。
- 镜头怎么摆。
- 每个时间段做什么动作。
- 适合什么时候发布。
- 评论区如何互动。

这部分对应赛题中的内容方向、选题建议、发布策略和互动优化。

### 5.4 导入参考作品

用户可以粘贴参考作品链接，或选择本地参考视频。系统进入动作识别流程：

- 识别人物动作。
- 对齐音乐卡点。
- 生成领拍参考。

当前已预留可灵 motion-control / image2video 接口。如果线上生成耗时过长或失败，使用本地示例动作继续演示。

### 5.5 AI 生成编舞

用户可以输入想拍的风格，例如“甜酷一点，动作慢一点，适合自拍”，也可以补充参考视频和 BGM 说明。系统尝试生成新的竖屏领拍参考，或者使用示例动作兜底。

### 5.6 手机化练习录制

拍摄页模拟短视频相机：

- 竖屏取景。
- 领拍参考小窗。
- 原作品/领拍切换。
- 倍速练习。
- 镜像模式。
- 骨架匹配分数。
- 录制和回放。
- 保存 WebM 成片。

用户最终得到的不只是建议，而是一条可以继续发布的作品。

## 6. AI 能力说明

### 趋势理解

通过社媒热点、同音源内容和互动数据，判断哪些内容适合普通 KOC 跟拍。Demo 中使用预置趋势卡片模拟，后续可接入平台热榜和数据分析模型。

### 视频理解

识别参考视频中的人物动作、节奏、手部细节、镜头语言和表情变化，为动作拆解和领拍生成提供输入。

### AIGC 领拍生成

通过可灵 image2video / omni-video / motion-control 等接口生成竖屏动作参考，让用户可以跟着更清晰的人物动作练习。

### 姿态估计

使用 MediaPipe Pose 在练习页进行人体骨架识别，形成动作匹配反馈，帮助用户判断动作是否接近参考。

### 发布策略生成

围绕标题、标签、发布时间、评论区钩子和复拍建议，生成更贴近社媒增长目标的运营建议。

## 7. 原型说明

当前可交互原型包含以下页面和状态：

1. 首页热榜：显示趋势卡片、AI 生成编舞入口、底部导航。
2. 解析弹层：展示 AI 正在拆解热点和生成领拍内容。
3. 趋势拆解：展示拍摄建议、动作分段和发布互动建议。
4. 导入弹窗：支持链接和本地视频输入，展示动作识别流程。
5. 手机拍摄页：展示领拍参考、练习控制、录制和成片回放。

视觉上采用手机化短视频界面，降低用户理解成本；电脑端访问时仍保持居中的手机画布，适合 16:9 横屏录屏展示。

## 8. 技术实现

前端：

- React 19。
- TypeScript。
- Vite。
- Tailwind CSS。
- motion 动效。
- lucide-react 图标。

媒体能力：

- HTML Video 播放趋势和领拍素材。
- MediaRecorder API 录制用户练习。
- MediaPipe Pose 做骨架识别和匹配反馈。

服务端与 AI 接口：

- Express 本地代理。
- GitHub Pages 静态网页发布。
- Vercel Serverless API，用于线上真实调用可灵接口。
- 可灵 API：image2video、omni-video、motion-control、任务查询。
- 本地素材兜底：保证演示流程稳定。

参考人物图：

- `public/reference-character.png` 是线上接口默认使用的参考人物图，GitHub Pages 或 Vercel 部署后都会通过 `/reference-character.png` 形成可访问 URL。
- `参考人物` 目录保留原始参考人物素材，便于评审查看和后续替换。
- image2video 会把参考图作为 `image` 参数；omni-video 会把参考图加入 `image_list`；motion-control 会把参考图作为 `image_url`，并把用户参考视频作为 `video_url`。

## 9. 落地规划

短期版本：

1. 接入真实热榜或运营后台数据，替换预置趋势卡片。
2. 增强视频理解，自动拆解动作分段、难度和卡点。
3. 优化录制后评分，给出更具体的动作纠错建议。
4. 支持一键导出发布文案、标签和封面建议。

中期版本：

1. 建立 KOC 账号画像，根据用户风格推荐不同内容方向。
2. 接入多平台内容数据，形成跨平台热点判断。
3. 支持同一热点的多版本 A/B 创意生成。
4. 生成评论区互动回复建议，提高发布后的运营效率。

长期版本：

1. 形成“趋势发现 -> 创意生成 -> 拍摄执行 -> 发布优化 -> 数据复盘”的完整 Agent。
2. 与智能营销投放平台结合，将自然流量内容和广告素材生产联动。
3. 支持更多低门槛内容类型，例如口播、剧情、AI 小游戏挑战和品牌互动玩法。

## 10. Demo 录屏建议

录屏控制在 3 分钟以内，建议顺序：

1. 开场说明普通 KOC 痛点。
2. 展示首页热榜和适合拍评分。
3. 点击开拍，展示 AI 解析流程。
4. 展示趋势拆解中的拍摄和发布建议。
5. 展示导入作品或 AI 生成编舞。
6. 进入手机化拍摄页，展示练习、录制和回放。
7. 收尾强调产品闭环和赛题价值。

## 11. 作品亮点

1. 贴合赛题：围绕普通 KOC 涨粉，覆盖选题、内容生产、发布策略和互动优化。
2. 闭环完整：不是只做生成，而是从热点判断到拍摄完成。
3. 演示稳定：真实 AI 接口与本地素材兜底结合，保证评审可完整体验。
4. 场景聚焦：选择手势舞这一高传播、低门槛、高模仿性的内容场景。
5. 可扩展：后续可接入真实社媒数据、账号画像和自动化运营 Agent。
